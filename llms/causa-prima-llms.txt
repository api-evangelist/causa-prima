# Scribo

> Free, EN 16931-compliant e-invoicing — ZUGFeRD/XRechnung for Germany, plain PDF for the US, more coming. Web UI, HTTP API, MCP server, CLI, or skill.

Scribo is a free, EN 16931-compliant e-invoicing tool. It generates compliant invoices through five surfaces — a Web UI, an HTTP API, a hosted MCP server, an npm CLI, and a Claude / Codex skill — all backed by the same /api/v1 API. No credit card; the sender's email is the login, via a lightweight magic-link sign-in.

## Integrations

- [Scribo Skill for Claude, ChatGPT & Codex](https://scribo.causaprima.ai/docs/skill): Install the Scribo skill in Claude.ai, Claude Code, Claude Desktop, Cowork, ChatGPT, or Codex CLI — /plugin install, git clone, or .zip upload.
- [Scribo MCP Server](https://scribo.causaprima.ai/docs/mcp): Hosted Scribo MCP server at scribo.causaprima.ai/mcp — connect Claude Desktop, Cursor, Cline, ChatGPT App, or Codex CLI over Streamable HTTP. No install.
- [Scribo CLI](https://scribo.causaprima.ai/docs/cli): Generate EN 16931 e-invoices from the terminal with @causaprima/scribo-cli — create, get, download, jurisdictions. Sysexits-style exit codes for CI use.
- [Scribo HTTP API](https://scribo.causaprima.ai/docs/api): REST reference for the Scribo /api/v1 public API — generate EN 16931 e-invoices, verify sender emails, list jurisdictions. Anonymous, rate-limited per IP.

## Glossary

- [What Is XRechnung? Germany's B2G E-Invoice Standard, Explained](https://scribo.causaprima.ai/glossary/xrechnung): XRechnung is the structured XML e-invoice format mandatory for billing German public authorities. What it is, UBL vs CII, when it's required, the Leitweg-ID, and how to create one.
- [What Is ZUGFeRD? The Hybrid PDF/XML E-Invoice Format, Explained](https://scribo.causaprima.ai/glossary/zugferd): ZUGFeRD is a German hybrid e-invoice: a readable PDF with EN 16931 XML embedded inside it. What it is, the profiles (BASIC, COMFORT), which satisfy the mandate, and how to create one.
- [ZUGFeRD vs XRechnung: Which German E-Invoice Format Do You Need?](https://scribo.causaprima.ai/glossary/zugferd-vs-xrechnung): ZUGFeRD and XRechnung are both German EN 16931 e-invoice formats. The difference: ZUGFeRD is a hybrid PDF for B2B, XRechnung is pure XML for B2G. A clear comparison and decision guide.
- [What Is EN 16931? The European E-Invoicing Standard, Explained](https://scribo.causaprima.ai/glossary/en-16931): EN 16931 is the European standard that defines a common data model for electronic invoices. What it covers, the legal basis, syntaxes, and how national formats like XRechnung and ZUGFeRD relate to it.
- [Germany's B2B E-Invoicing Mandate (2025–2028): Timeline & Formats](https://scribo.causaprima.ai/glossary/german-e-invoicing-mandate): Germany is phasing in mandatory structured e-invoices for domestic B2B. A factual overview of the timeline — receive capability in 2025, issuing obligations in 2027 and 2028 — and which formats qualify.
